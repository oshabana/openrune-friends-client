1

Install Java 21

Get Temurin Java 21 if it is not already installed.

2

Open the launcher

Extract the zip and open Launch OpenRune. On Mac, approve the network prompt. If macOS blocks the file, right-click it and choose Open.

3

Choose the world

In RSProx, select OpenRune Friends, choose RuneLite, and launch. Sign in to world 255.

Quest Helper and 117 HD are selected for RuneLite's Plugin Hub on first launch. If either one does not appear, open RuneLite's wrench icon and install it from Plugin Hub. Full instructions and checksums.
